# 💎 Jewellra Frontend

Modern Jewellery E-Commerce Frontend built with Next.js, TypeScript, Tailwind CSS, and Firebase.

## 🚀 Features

- User Authentication
- Product Catalog
- Wishlist
- Shopping Cart
- Responsive Design

## 🛠️ Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Firebase

## 📦 Installation

```bash
npm install
npm run dev
```
